<Note>
  Miden publishing is part of the stable `pragma-sdk` release behind the `[miden]` extra. The Miden testnet runs node **0.16** since September 2026: use `pragma-sdk >= 2.14.4` (`pm-publisher >= 0.1.0a12`), older releases are rejected by the node.
</Note>

Publishers submit price data directly to their own Miden account. The Oracle reads from all registered publishers when computing the median.

If you are already publishing on Starknet via `pragma-sdk`, adding Miden support requires minimal changes — the same pipeline pushes to both networks automatically.

---

## Step 1 — Install

```bash
pip install 'pragma-sdk[miden]'
```

The `[miden]` extra pulls in `pm-publisher`, the Rust-backed Python wheel that drives the Miden client. No Rust toolchain required.

---

## Step 2 — Initialize your publisher account

Run this once. It creates your publisher account on Miden and writes your credentials locally. Pass the Pragma oracle id (see the [pragma-miden README](https://github.com/astraly-labs/pragma-miden#deployments)): it is stored next to your publisher id.

```python
import asyncio
from pragma_sdk.miden.client import PragmaMidenClient

async def main():
    client = PragmaMidenClient(
        network="testnet",
        oracle_id="0x3b306d819a19b691205480e1619b5c",  # Pragma oracle on the 0.16 testnet
    )
    await client.initialize()
    print(f"Your publisher ID: {client.publisher_id}")

asyncio.run(main())
```

This creates three files in your working directory:

| File | Purpose |
|------|---------|
| `pragma_miden.json` | Your publisher ID and oracle address |
| `keystore/` | Account signing keys — back this up |
| `miden_storage/store.sqlite3` | Local chain state |

<Warning>
  Back up your `keystore/` directory. Losing it means losing access to your publisher account.
</Warning>

## Step 3 — Fund your account

Miden 0.16 charges every transaction a fee in the chain's native asset, paid from your account's vault: about **112 base units per 14-entry batch**, 119 for the registration, nothing for reads. On testnet the only source is the public faucet. Your account is created with `BasicWallet`, so it can receive the faucet's note:

```python
balance = await client.maintain_fee_balance()   # 0 → asks the faucet for 100 tokens (100_000_000 base units)
print(balance)                                  # ≈ 99_999_881 after the note is consumed
```

`maintain_fee_balance()` reads the balance (`fee_balance()`) at most every 10 minutes and, below `FEE_REFILL_THRESHOLD` (2 000 000 base units, ~15 h of publishing at one batch every 3 s), solves the faucet's proof-of-work, mints a note and consumes it. It never raises: failures are logged and counted. 100 tokens cover roughly 10 months of continuous publishing, so refills are rare. The same is available from the CLI: `pm-publisher-cli -n testnet fund` / `balance`.

## Step 4 — Get registered

Share your publisher ID (from `pragma_miden.json`) with the Pragma team. We will register it on the oracle so your prices are included in the median computation.

```json
{
  "networks": {
    "testnet": {
      "publisher_account_ids": ["0x<your-publisher-id>"]
    }
  }
}
```

<Note>
  Registration is currently manual. Reach out via [Discord](https://discord.gg/pragma) or [Telegram](https://t.me/pragma_oracle).
</Note>

## Step 5 — Publish prices

Once registered, publish entries as part of your existing data pipeline:

```python
import asyncio
from pragma_sdk.miden.client import PragmaMidenClient, MidenEntry

async def main():
    client = PragmaMidenClient(network="testnet")   # oracle_id read from pragma_miden.json
    await client.initialize()

    entries = [
        MidenEntry(pair="1:0", price=8_500_000_000_000, decimals=8),  # BTC/USD = $85,000.00
        MidenEntry(pair="2:0", price=220_000_000_000,   decimals=8),  # ETH/USD = $2,200.00
    ]

    results = await client.publish_entries(entries)
    print(results)  # [True, True]

asyncio.run(main())
```

`publish_entries` submits a single batched Miden transaction containing all entries, regardless of how many pairs you push. A failure aborts the batch (atomic), but the next tick retries naturally.

When converting from a `pragma-sdk` Starknet `Entry`, use `MidenEntry.from_starknet_entry(entry)` — it resolves `decimals` from the pair's currencies (`min(base.decimals, quote.decimals)`), so you never have to hardcode them.

## Starknet + Miden together (`price-pusher`)

If you run the `price-pusher`, Miden publishing is enabled with one extra flag. It runs as its **own loop**, decoupled from the Starknet push cadence: every `--miden-publish-interval` seconds (default `3`) the latest polled prices are published to Miden in one batched transaction, whether or not Starknet pushed anything. Miden calls are offloaded to a thread with per-call timeouts, so a hung or slow Miden node never affects Starknet, and a Starknet outage (out of gas, RPC down) never stops the Miden feed.

```bash
price-pusher \
  --config-file config.yaml \
  --network mainnet \
  --private-key plain:0x... \
  --publisher-name MY_PUBLISHER \
  --publisher-address 0x... \
  --miden-network testnet \
  --miden-publish-interval 3 \
  --miden-config-path /path/to/pragma_miden.json \
  --miden-storage-path /path/to/miden_storage \
  --miden-keystore-path /path/to/keystore
```

`--miden-network` accepts `testnet`, `devnet` or `local`. `--miden-oracle-id` overrides the oracle read from `pragma_miden.json`. The three path flags are optional and default to the working directory. If Miden initialization fails at startup, Miden publishing is disabled with an error log and the Starknet pusher keeps running.

The pusher dedupes entries by pair using the **median** of source prices before forwarding to Miden, so a tick with `BTC/USD × 5 sources` produces a single `BTC/USD` entry on Miden. Only pairs present in `STARKNET_PAIR_TO_MIDEN_FAUCET` are forwarded; the rest are silently skipped.

The pusher also keeps the account funded: after each Miden tick it calls `maintain_fee_balance()` and exposes `pragma_miden_fee_balance{account}` and `pragma_miden_refills_total{account,result}` on `/metrics`, so you can alert on a low balance or a failed refill.

## Available pairs

| faucet_id | Asset      | decimals | Starknet       |
|-----------|------------|----------|----------------|
| `1:0`     | BTC/USD    | 8        | also published |
| `2:0`     | ETH/USD    | 8        | also published |
| `3:0`     | WBTC/USD   | 8        | also published |
| `4:0`     | USDT/USD   | 6        | also published |
| `5:0`     | DAI/USD    | 8        | also published |
| `6:0`     | ZEC/USD    | 8        | Miden only     |
| `7:0`     | XMR/USD    | 8        | Miden only     |
| `8:0`     | DASH/USD   | 8        | Miden only     |
| `9:0`     | XAUT/USD   | 6        | Miden only     |
| `10:0`    | PAXG/USD   | 8        | Miden only     |
| `11:0`    | LINK/USD   | 8        | Miden only     |
| `12:0`    | UNI/USD    | 8        | Miden only     |
| `13:0`    | AAVE/USD   | 8        | Miden only     |
| `14:0`    | MORPHO/USD | 8        | Miden only     |

The pusher resolves decimals dynamically from each pair's currencies (`min(base.decimals, quote.decimals)`); you don't have to hardcode them. To add a pair, extend `STARKNET_PAIR_TO_MIDEN_FAUCET` in `pragma_sdk/miden/client.py` and make sure both currencies are in `supported_assets.yaml`.

To publish a pair on Miden **without** pushing it to Starknet, put it in a price-pusher config group flagged `miden_only: true`: the group is polled by the fetchers and forwarded to Miden, but no Starknet listener is created for it. This is how `6:0` to `14:0` are published:

```yaml
- pairs:
    spot:
      - ZEC/USD
      - XAUT/USD
  time_difference: 1800
  price_deviation: 0.01
  miden_only: true
```

## API reference

```python
class PragmaMidenClient:
    def __init__(
        self,
        network: str = "testnet",                 # "testnet" | "devnet" | "local"
        oracle_id: str | None = None,             # read from pragma_miden.json if omitted
        storage_path: str | None = None,
        keystore_path: str | None = None,
        config_path: str | Path | None = None,    # path to pragma_miden.json
    ): ...

    async def initialize(self) -> None: ...                                  # idempotent
    async def publish_entries(self, entries: list[MidenEntry]) -> list[bool]: ...
    async def get_entry(self, pair: str) -> MidenEntry | None: ...           # None on failure
    async def sync(self) -> None: ...
    async def fee_balance(self) -> int: ...                                  # base units of the fee asset
    async def maintain_fee_balance(self, threshold: int = FEE_REFILL_THRESHOLD) -> int | None: ...  # faucet refill below threshold

class MidenEntry:
    pair: str       # faucet_id, e.g. "1:0"
    price: int      # integer scaled by 10**decimals
    decimals: int
    timestamp: int  # unix timestamp, defaults to now

    @classmethod
    def from_starknet_entry(cls, entry) -> MidenEntry | None:
        """Convert a Starknet Entry. Returns None if the pair is unsupported on Miden
        or if its decimals cannot be resolved."""
```
